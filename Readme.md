#  COVID Chest X-Ray Clustering Project
The COVID Chest X-Ray Clustering Project is a comprehensive analysis of COVID-19, Pneumonia, and Normal chest X-ray images using deep learning models and clustering algorithms. The project aims to provide insights into the clustering behavior and label drift of the images, enabling the development of more accurate diagnostic models. The project consists of three main components: data preprocessing and feature extraction, clustering analysis, and accuracy comparison of different models.

## 🚀 Features
- Data preprocessing and feature extraction using deep learning models
- Clustering analysis using various clustering algorithms (e.g., KMeans)
- Accuracy comparison of different deep learning models and clustering algorithms
- Label drift analysis and computation of label change percentages
- Data visualization and performance metric computation

## 🛠️ Tech Stack
- **Frontend:** None
- **Backend:** Python
- **Database:** None
- **AI Tools:** TensorFlow, Keras, scikit-learn
- **Build Tools:** None
- **Libraries:** numpy, pandas, scipy, joblib, threadpoolctl, matplotlib, seaborn

## 📦 Installation
To install the required libraries, run the following command:
```bash
pip install tensorflow keras scikit-learn numpy pandas scipy joblib threadpoolctl matplotlib seaborn
```

1. Clone the repository
2. Install the required libraries
3. Run the `covid_pneumonia_normal.ipynb` notebook for data preprocessing and feature extraction
4. Run the `clustering_covid.ipynb` notebook for clustering analysis
5. Run the `ACCURACY COMPARISON COVID.ipynb` notebook for accuracy comparison
